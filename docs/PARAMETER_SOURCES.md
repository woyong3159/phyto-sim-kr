# PARAMETER_SOURCES — 파라미터 출처 누적

형식: 파라미터 경로 · 값 · 태그 · 출처(문헌명, 발행처, 연도, 쪽/표) · 교차 확인 출처 · 비고

## Phase 0
등록된 생리·경제 파라미터 없음(0개). `/data/*.json` 20개 파일은 뼈대만 있다.

규칙(헌법 4항 N8, 8항):
- 존재하지 않는 논문·URL·통계는 적지 않는다.
- 핵심 파라미터는 최소 2개 출처로 교차 확인하고, 확인하지 못한 값은 EST 태그와 추정 논리를 적는다.
- 벤치마크에 맞춘 값은 CAL 태그로 원래 값과 보정 사유를 남긴다.
