## 결정 기록 (사용자 대신 내린 기술 결정)
- 하단 탭 6개: 대시보드 / 환경 / 근권·양액 / 작물 / IPM / 더보기(세이브·자동 일시정지·시스템 점검).
- 상단 시간바는 모든 탭에 고정. 배속 6단, 턴 버튼 3개(+1시간·다음 날 = +24시간·다음 주 = +168시간).
- 배포 경로는 상대 경로(base './') → GitHub Pages·Cloudflare Pages·Netlify 어디든 수정 없이 올라간다.
- 엔진 워커는 앱 파일 안에 포함(inline) → PWA와 단일 파일 빌드가 같은 코드 경로.
- 난수: sfc32(정수 연산) + 영역별 독립 흐름. 기상은 하루에 정확히 12개를 고정 순서로 뽑는다.
- 수학 함수: 엔진 전용 구현(dmath)만 쓴다 → 아이폰과 PC에서 비트 단위로 같은 결과.
- 기상 특보는 "발생시키는" 것이 아니라 생성된 기온·강수 계열에서 기상청 기준 충족 여부를 판정한다(태풍·우박·장마 시기만 확률 발생).
- 세이브 스키마 v2: 지역, 자동 일시정지 설정 추가. v1 세이브는 지역 = 부여로 옮겨진다.
- 엔진 상태 구조가 바뀐 옛 스냅샷은 버리고 조치 로그로 다시 계산한다.
