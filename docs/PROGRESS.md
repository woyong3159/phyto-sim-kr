- 딸기 생육 조사 자료(화방별 착과 수·과중, 엽수, 분얼 수, 월별 수량)가 있으면 겨울철 sink 제한 문제(KNOWN_LIMITS S3)를 보정할 수 있다.
- 재배하면서 조사한 오이 생육 조사표(마디 수, 엽장·엽폭, 과실 비대 일수)가 있다면 모델 보정에 가장 큰 도움이 된다.

## 결정 기록 (사용자 대신 내린 기술 결정)
- 하단 탭 6개: 대시보드 / 환경 / 근권·양액 / 작물 / IPM / 더보기(세이브·자동 일시정지·시스템 점검).
- 상단 시간바는 모든 탭에 고정. 배속 6단, 턴 버튼 3개(+1시간·다음 날 = +24시간·다음 주 = +168시간).
- 배포 경로는 상대 경로(base './') → GitHub Pages·Cloudflare Pages·Netlify 어디든 수정 없이 올라간다.
- 엔진 워커는 앱 파일 안에 포함(inline) → PWA와 단일 파일 빌드가 같은 코드 경로.
- 난수: sfc32(정수 연산) + 영역별 독립 흐름. 기상은 하루에 정확히 12개를 고정 순서로 뽑는다.
- 수학 함수: 엔진 전용 구현(dmath)만 쓴다 → 아이폰과 PC에서 비트 단위로 같은 결과.
- 기상 특보는 "발생시키는" 것이 아니라 생성된 기온·강수 계열에서 기상청 기준 충족 여부를 판정한다(태풍·우박·장마 시기만 확률 발생).
- 세이브 스키마 v2: 지역, 자동 일시정지 설정 추가. v1 세이브는 지역 = 부여로 옮겨진다.
- 엔진 상태 구조가 바뀐 옛 스냅샷은 버리고 조치 로그로 다시 계산한다.
- (Phase 2) 온실은 공기 + 축열체 2절점, 10분 서브스텝은 지수 해. 헌법의 에너지 식에 없는 축열체 절점을 추가했다(무가온 야간 보온 재현에 필요).
- (Phase 2) 피복 겹수(1중/2중)를 구성 항목에 추가 — 국내 가온 재배의 표준이 2중 피복이라 난방 소비량 현실성에 필수.
- (Phase 2) 온풍기는 10분 스텝 도중에도 상한 온도에서 꺼지는 것으로 계산(스텝 해상도 때문에 생기는 과도한 과열·연료 낭비 방지).
- (Phase 2) 난수 흐름 `failure` 추가(장비 고장 전용). 날씨는 장비 구성과 무관하게 같은 seed면 같다.
- (Phase 2) 기본 제어 설정: 주간 14 / 야간 12 / 일출 전 13°C, 환기 25°C, 습도 상한 92%. 국내 과채류 관행 수준으로 잡았다.
- (Phase 2) 세이브 스키마 v3. v2 세이브는 연동 비닐하우스 기본 구성으로 옮겨진다.
- (Phase 3a) 광합성은 온실 모델의 10분 서브스텝 안에서 계산한다(CO2 수지와 작물 탄소 수지를 같은 숫자로 맞추기 위해). 작물 모듈은 그 합계를 받아 1시간 단위로 생장을 계산한다.
- (Phase 3a) 과실·암꽃은 난수 없이 기대값(분수)으로 계산한다. 유과 퇴화도 확률이 아니라 비율이다(N2: 랜덤 허용 영역이 아님).
- (Phase 3a) 사건 종류 `crop` 추가(고사, 첫 수확, 철거). 세이브 스키마 v4, 엔진 상태 v4.
- (Phase 3a) 시험용 군락(testLai)은 검증 도구 전용으로만 남기고 화면에서 없앴다. 기본 구성은 빈 온실이다.
- (Phase 3a) V4(수량 ±25%)는 병해충·근권이 들어가기 전이라 미달로 기록하고, 수치를 억지로 맞추지 않았다.
- (Phase 3b) 딸기 체내 질소는 Phase 4 전까지 작업 계획의 임시 입력(nLevel)으로 둔다.
- (Phase 3b) 육묘장 화아분화는 그 지역 평년값으로 계산한다(작기 시작 전의 실제 날씨는 생성하지 않기 때문).
- (Phase 3b) 표준 정식일은 9월 20일(중부 자연 분화 직후). 기본 재식밀도 8.5주/m², 꿀벌, 화방당 7화, 관부 2개.
- (Phase 3c) 와사비 벤치마크는 소득자료집에 항목이 없어 국내 물재배 시험 성적(567–782 kg/10a)으로 대신했다.
- (Phase 3c) 와사비 표준 관리: 55% 차광(맑은 날), 패드앤팬 22°C, 포그, 양액 12–17°C, 난방 8°C, Daruma 8주/m², 18개월 수확.
- (Phase 3c) 새 작기를 작물과 함께 시작하면 제어 설정이 그 작물의 표준값(crops.json recommend)으로 시작한다. 시설·장비(차광막·냉방)는 사용자가 고른다.
- (Phase 4) 질문 없음(지시문이 충분히 구체적). 추천값으로 정한 것: 작물별 기본 근권 — 오이 암면·배출식·네덜란드 배출식 표준액 EC 2.0→2.4(30일)·pH 5.6·일사비례 100 J/cm²·150 mL/주·배액 30%; 딸기 코이어·배출식·야마자키 EC 0.8→1.0(40일)·pH 5.8·250 J/cm²·60 mL/주·배액 30%; 와사비 DFT·순환·1/2 원시처방 EC 1.0·pH 6.2·에어펌프·UV·30일 교체. 원수는 지역 지하수, 혼합기, EC·pH 미터 보유.
- (Phase 4) 원액 탱크 A·B 500 L, 산 200 L, 희석 1:100(산 1:200), 자동 보충 켜짐. 탱크 재고는 온실 전체 L로, 급액·근권은 바닥 m²당으로 센다.
- (Phase 4) 관측 모드 기본은 학습. 현실 모드는 화면 표시만 바꾸고 결과에는 영향이 없다(세이브에 기록).
- (Phase 4) 세이브 스키마 v5, 엔진 상태 v7. 옛 작기는 정식 작물의 기본 근권으로 다시 계산된다.
- (Phase 4) 처음 계획과 다른 작물을 작물 탭에서 심을 때, 근권을 손대지 않았으면 그 작물의 기본 근권을 함께 적용한다(조치 로그에 남는다).
- (Phase 4) 딸기 체내 질소 임시 입력(nLevel)은 자가 육묘의 육묘기 질소로만 남기고, 정식 뒤는 근권 모델의 신엽 질소를 쓴다.
